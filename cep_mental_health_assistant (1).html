Technical Architecture & Netlify Deployment

Single-File SPA Architecture

Built using pure vanilla JavaScript, HTML5 semantic layout, dynamic DOM state management, and Tailwind CSS. Runs completely offline without complex Node build tools.

Netlify & Mobile PWA Ready

Configured for direct drop-in hosting on Netlify. Includes web app manifest header meta tags, allowing users to select "Add to Home Screen" on Android and iOS devices.
